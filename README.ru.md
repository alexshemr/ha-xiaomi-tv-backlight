# Подсветка Xiaomi TV для Home Assistant

Основная инструкция — [на английском](README.md).

Это дополнительная интеграция для автоматизаций. Основное назначение
[приложения на ТВ](https://github.com/alexshemr/xiaomi-tv-backlight-control) —
управление подсветкой с пульта.

Добавьте этот репозиторий в HACS → Пользовательские репозитории, категория
Integration. Установите компонент и перезапустите HA. На ТВ откройте сопряжение,
добавьте найденную интеграцию в HA и введите код с телевизора.

Появятся ползунок подсветки и диагностический датчик соединения. При недоступности
ТВ ползунок показывает 0%, датчик выключается. Пример автоматизации сна приведён
в английской инструкции. Подставьте реальные идентификаторы своих сущностей.
