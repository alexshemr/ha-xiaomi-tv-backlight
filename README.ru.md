# Xiaomi TV Backlight для Home Assistant

Управление подсветкой Xiaomi TV из автоматизаций Home Assistant.
Например, снижение подсветки при включении режима сна.

Требуется [приложение на ТВ](https://github.com/alexshemr/xiaomi-tv-backlight-control).

## Настройка

1. Добавьте этот репозиторий в HACS → Пользовательские репозитории → **Integration**.
2. Установите интеграцию и перезапустите Home Assistant.
3. На ТВ откройте «Связать с Home Assistant».
4. Добавьте **Xiaomi TV Backlight Control** в HA и введите код с телевизора.

Появятся сущность подсветки (0–100%) и датчик соединения.
Обновление каждые 15 секунд. При недоступном ТВ отображается 0%.

Пример [автоматизации сна](README.md#sleep-automation) — в английской инструкции.
Замените идентификаторы сущностей своими.

Проверено на **HA 2026.10.1, MiTV-MSSP1, Android TV 9, PI.5925**.
